## [0.1.0] - 2026-11-16

### Added

- Windows-validated Qt GUI testing bridge for QWidget and QWindow applications.
- Widget-tree discovery with QWidget, QWindow, and QAction metadata.
- Semantic button and QAction activation, text entry, keyboard and mouse input.
- Popup error inspection, Qt log capture, screenshots, and automatic script
  screenshots.
- Readable line-oriented UI test scripts and MCP client setup tooling.
- C++ QtTest and Python adapter test coverage.
